Ubicación del reporte

Se adjunta al siguiente reporte. La página no pide la ubicación al abrirse.

Necesitamos tu ubicación aproximada para adjuntar las coordenadas al reporte técnico. El navegador preguntará después de este aviso. Si no quieres compartirla, podrás elegir la zona a mano.

Bandeja de Salida

    Instalar aplicación

    En Chrome o Edge aparece el botón cuando el navegador ya puede instalarla. En iPhone la instalación se hace desde el menú del navegador.

    Para instalar en iPhone, pulsa el icono Compartir y selecciona “Agregar a inicio”.

    Cámara

    Primero lee el aviso. La vista previa se queda en este teléfono y no se envía a ningún servidor.

    Esta aplicación requiere acceso a tu cámara únicamente para mostrar una vista previa local en pantalla. Ninguna imagen se envía a servidores externos. Primero se encenderá la cámara trasera.
